# 添加界面语言

语言文件从 `BepInEx/plugins/CustomDancePlayer/Locales` 自动读取，添加语言无需修改 DLL。

1. 复制 `en.json`，按语言代码命名，如 `ja.json`、`ko.json`、`fr.json`、`zh-TW.json`。
2. 保留左侧键，翻译右侧文字。使用 UTF-8，JSON 内不加注释。
3. 设置 `"language.name": "日本語"`，作为设置页显示名称。
4. 保留 `{0}`、`{1}` 等参数占位符及其编号。文件放好后重启游戏，或重新选择一次语言；点击语言按钮依次切换。

简化示例：

```json
{
  "language.name": "日本語",
  "composer.title": "タイトル",
  "composer.author": "作者"
}
```

可以逐步翻译：缺少的键回退到英文。格式错误的 JSON 跳过并记录日志；参数格式错误的文字使用英文。语言文件名匹配忽略大小写；跟随系统先匹配完整代码，再匹配同一语言前缀，最后使用英文。

翻译者检查完整／迷你面板、导入制作、设置与悬停帮助，特别注意长按钮文字和数字参数。界面使用已有字体回退，新增语言仍需检查本机能否显示相应字符。BepInEx 与迁移脚本保持英文，独立于界面语言。

当前随包提供英文与简体中文。
