# 导入与制作

![制作页面](../images/composer-zh-CN.png)

VMD 播放是这次新加的功能，还有一些动作需要继续完善。如果遇到问题，请在 [GitHub 提交 Issue](https://github.com/maoxig/MateEngine-CustomDancePlayer/issues)，最好附上对应的 VMD、模型和复现步骤，我会继续检查和修复。

## 制作一首舞蹈

1. 选择身体动作 `.vmd`，再选择音频。手上有一整套 MMD 素材时，也可以选择目录自动配对。
2. 填写“标题”和“文件名标识”。标题显示在舞蹈库，标识用于文件名与库中的 ID，例如 `catch-the-wave`。
3. 点击“校验”，查看素材是否能读取，再“加入并预览”。底栏可以暂停、跳转进度和停止。
4. 调好音乐同步、镜头与 IK 后，导出 `.vmdance`，或者保存当前打开的舞蹈包。

## VMD 应该放在哪一栏

身体动作是必选项，需要包含骨骼动作。一个 VMD 同时包含身体、表情和口型时，只放在身体动作栏即可，里面的表情会一起读取。

| 素材 | 填写位置 |
| --- | --- |
| 包含骨骼动作的 VMD | 身体动作 |
| 独立表情或口型 VMD | 高级选项中的表情／口型 |
| 独立镜头 VMD | 高级选项中的镜头 |
| OGG、WAV、MP3 | 音频，可选 |
| 动作所需的特殊参考 PMX | 高级选项中的参考 PMX |
| 需要覆盖或补充轨道的 VMD | 附加图层，后面的图层覆盖同名轨道 |

同一文件重复填入表情／口型栏时会去重。身体文件自带镜头时也可以直接使用。只有镜头或只有表情的 VMD 不能代替身体动作。

参考 PMX 用来解释动作的 MMD 骨架，和 MateEngine 中使用的 VRM 角色是两回事。通常使用插件自带的参考模型即可。

## 音乐同步

开始预览后，用“音乐提前／延后”边听边调。步长可以切换 0.1、0.01 和 1 秒，也可以直接输入秒数或归零。负数表示音乐提前，正数表示延后。

预览中的调整即时生效，暂停时也可以调。满意后保存修改或导出舞蹈包。

## 镜头参考与脚步 IK

制作页自动获取当前角色的原始视线高度，滚轮放大角色不改变这个数值。预览带镜头的动作，再拖动“参考倍率”滑块调整构图；这两个值一起写入舞蹈包。

换用其他角色时，自动倍率为：

```text
当前角色视线高度 ÷ 包内参考视线高度 × 包内参考倍率
```

例如参考视线 1.4 m、参考倍率 0.5，换成视线 0.7 m 的角色时，得到 0.25 倍。打开已有包时保留作者的参考值；要重新标定，请切回制作时的角色，再点击“获取当前模型”。没有包内参考信息的旧舞蹈使用 1.65 m 基准。

“包内脚步 IK”可以选择默认、跟随 VMD 或关闭。通常使用默认；已经烘焙了 FK 的动作可以尝试关闭。这个选择跟随舞蹈包保存，换角色时继续使用。

设置页的“全局”选项用于个人播放偏好。制作时的镜头预览使用包内参考，方便作者确定舞蹈本身的构图。

## 修改已有舞蹈包

点击“打开舞蹈包”，选择 `.vmdance`，页面会恢复素材、标题、音频偏移、镜头参考、IK 和图层。修改后可以再次校验、预览。

“保存修改”更新原包并保留备份；“导出舞蹈包”另存一份。素材已包含在包中，打开时会解包供编辑。

## 借物表 / Credits

高级信息底部可以填写素材作者、来源、链接或其他备注。这里是自由文本，格式不限。例如：

```text
Camera: XXX
Motion: XXX
Model: XXX
```

换行和文字随 `.vmdance` 保存，打开已有包时恢复；保存修改或导出副本也会保留。

## 制作 `.unity3d` 舞蹈

制作页用于 `.vmdance`。如果希望把 VMD 转成以前的 `.unity3d` 动画包，可以使用我的 [UnityMMDConverter](https://github.com/maoxig/UnityMMDConverter)，在 Unity 工程中完成转换、表情／镜头处理和打包。具体步骤见工具仓库的教程；导出后放入 `CustomDances` 即可。

使用、转换、打包或分享 MMD 素材前，请查看动作、镜头、模型、音乐等原作者的规定，遵守 MMD 社区约定。制作 `.vmdance` 时，也可以在借物表中记录作者与来源链接。
